**解释：两种短训练策略尚未优于规则控制，也未达到期末储能恢复要求。** 当前结果支持“程序链路可以运行”，不支持“算法已收敛”“成本已降低”或“可以投入现场运行”。不可行小时数为零也不包含尚未建模的网络与设备约束。

电、热、冷账目最大残差约为 $1.1\times10^{-13}$ kW；此残差只是数值账目检查。三个策略在该合成测试集均未发生弃风弃光，因此不能据此声称 DRL 提高了新能源利用率。

## 3. 证据文件

`examples/verification/` 保存规则、PPO、SAC 的测试汇总、每日指标、逐时结果和短训练日志；`examples/rule_dispatch.png` 和 `examples/ppo_learning_curve.png` 为实际输出。

短训练权重未作为发布模型提供，可按下列命令重新训练。模型摘要在测试报告中保留用于追溯本次运行，不保证不同依赖和硬件下生成完全相同的权重文件。

```bash
python -m ies_drl.train --algo ppo --steps 4096 --eval-every 2048 --out runs/ppo_smoke
python -m ies_drl.evaluate --policy ppo --run runs/ppo_smoke --out runs/ppo_smoke_test
python -m ies_drl.train --algo sac --steps 2048 --eval-every 2048 --out runs/sac_smoke
python -m ies_drl.evaluate --policy sac --run runs/sac_smoke --out runs/sac_smoke_test
```
